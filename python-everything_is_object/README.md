# python-everything_is_object

Answers and a script exploring how objects, identity and mutability work in Python (Ubuntu 20.04, Python 3.8.5, pycodestyle 2.7.*).

| File | Description |
|------|-------------|
| `0-answer.txt` | Function to print the type of an object |
| `1-answer.txt` | Function to get the identifier (memory address in CPython) of an object |
| `2-answer.txt` to `5-answer.txt` | Whether two names refer to the same integer object |
| `6-answer.txt` to `9-answer.txt` | Equality and identity of strings |
| `10-answer.txt` to `13-answer.txt` | Equality and identity of lists |
| `14-answer.txt`, `15-answer.txt` | `append` versus `+` on a list shared by two names |
| `16-answer.txt` to `18-answer.txt` | Passing integers and lists to functions |
| `19-copy_list.py` | Function `copy_list(l)` that returns a copy of a list |
| `20-answer.txt` to `23-answer.txt` | Tuple or not? |
| `24-answer.txt` to `26-answer.txt` | Identity of equal integers and tuples |
| `27-answer.txt`, `28-answer.txt` | `id` after `a = a + [5]` versus `a += [4]` |
