# Python - Hello, World

Introductory Python project covering Bash scripts that run Python code, `print`, f-strings, string slicing and concatenation.

| File | Description |
| --- | --- |
| `0-run` | Runs the Python file named in `PYFILE` |
| `1-run_inline` | Runs the Python code stored in `PYCODE` |
| `2-print.py` | Prints a quoted sentence |
| `3-print_number.py` | Prints an integer with an f-string |
| `4-print_float.py` | Prints a float to 2 decimal places |
| `5-print_string.py` | Prints a string three times and its first 9 characters |
| `6-concat.py` | Concatenates two strings |
| `7-edges.py` | Prints the edges and middle of a word |
| `8-concat_edges.py` | Builds a new sentence from slices |
| `9-easter_egg.py` | Prints the Zen of Python |
