# Python - Exceptions

Exercises on handling and raising exceptions in Python 3.8.5.

| File | Description |
| --- | --- |
| `0-safe_print_list.py` | Prints up to `x` elements of a list and returns the count printed |
| `1-safe_print_integer.py` | Prints an integer if possible, returns `True` or `False` |
| `2-safe_print_list_integers.py` | Prints only the integers among the first `x` items and returns the count |
| `3-safe_print_division.py` | Divides two integers and always prints `Inside result: ...` |
| `4-list_division.py` | Divides two lists element by element, reporting errors |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |

All files are executable, start with `#!/usr/bin/python3`, and are checked with pycodestyle.
