Doctests for the matrix_divided function defined in 2-matrix_divided.py
=======================================================================

Load the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a matrix of integers:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is not changed and a new matrix is returned:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]
    >>> result = matrix_divided(matrix, 3)
    >>> result is matrix
    False
    >>> result[0] is matrix[0]
    False
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Results are rounded to 2 decimal places:

    >>> matrix_divided([[1, 2, 10]], 3)
    [[0.33, 0.67, 3.33]]
    >>> matrix_divided([[-1, -2]], 3)
    [[-0.33, -0.67]]
    >>> matrix_divided([[1, 6, 7]], 6)
    [[0.17, 1.0, 1.17]]
    >>> matrix_divided([[1]], 7)
    [[0.14]]
    >>> matrix_divided([[1.2345, 9.8765]], 1)
    [[1.23, 9.88]]

All results are floats:

    >>> matrix_divided([[4, 8]], 2)
    [[2.0, 4.0]]
    >>> matrix_divided([[1, 2, 3]], 1)
    [[1.0, 2.0, 3.0]]
    >>> type(matrix_divided([[4]], 2)[0][0])
    <class 'float'>
