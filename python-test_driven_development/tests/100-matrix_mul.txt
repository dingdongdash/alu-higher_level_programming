===========================
Test cases for matrix_mul()
===========================

The function multiplies two matrices that are given as lists of lists of
integers or floats. Invalid arguments raise an exception whose message
names the argument, and the checks happen in a fixed order.

>>> matrix_mul = __import__('100-matrix_mul').matrix_mul

Sample products from the project page
-------------------------------------
>>> print(matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
[[7, 10], [15, 22]]
>>> print(matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
[[13, 16]]

The result is a new list of lists and the arguments are unchanged
-----------------------------------------------------------------
>>> m_a = [[1, 2], [3, 4]]
>>> m_b = [[5, 6], [7, 8]]
>>> result = matrix_mul(m_a, m_b)
>>> print(result)
[[19, 22], [43, 50]]
>>> m_a
[[1, 2], [3, 4]]
>>> m_b
[[5, 6], [7, 8]]
>>> type(result).__name__
'list'
>>> [type(row).__name__ for row in result]
['list', 'list']
>>> result is m_a or result is m_b
False
>>> result[0] is m_a[0] or result[0] is m_b[0]
False
>>> m_a = [[1, 1], [1, 1]]
>>> result = matrix_mul(m_a, m_a)
>>> result[0] is result[1]
False
>>> result[0][0] = 99
>>> print(result)
[[99, 2], [2, 2]]
>>> m_a
[[1, 1], [1, 1]]
>>> m_a = [[1, 2], [3, 4]]
>>> print(matrix_mul(m_a, m_a))
[[7, 10], [15, 22]]
>>> print(matrix_mul(m_a, m_a))
[[7, 10], [15, 22]]
>>> m_a
[[1, 2], [3, 4]]
