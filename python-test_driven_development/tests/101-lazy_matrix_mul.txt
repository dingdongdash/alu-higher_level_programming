================================
Test cases for lazy_matrix_mul()
================================

The function multiplies two matrices with NumPy. The valid products are
the same as for matrix_mul(), but invalid arguments raise the exceptions
of NumPy instead of the messages of matrix_mul(). These tests are pinned
to the behavior of NumPy 1.15.0, the version required by the project, and
they check the exact exception class: TypeError or ValueError. Other
versions of NumPy raise other classes for some of the inputs. The products
are shown as lists with tolist() so that no NumPy specific repr is printed.

>>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

The arguments are unchanged
---------------------------
>>> m_a = [[1, 2], [3, 4]]
>>> m_b = [[5, 6], [7, 8]]
>>> print(lazy_matrix_mul(m_a, m_b).tolist())

[[1, 2], [3, 4]]

[[5, 6], [7, 8]]

[[5, 6], [7, 8]]

Helper that tells which exception NumPy raised
----------------------------------------------
kind() gives the exact base class of the exception, the text no error
when there is none, and custom message for an exception that names m_a
or m_b, because NumPy messages never do.

>>> def kind(m_a, m_b):
...     try:
...         lazy_matrix_mul(m_a, m_b)
...     except Exception as e:
...         if 'm_a' in str(e) or 'm_b' in str(e):
...             return 'custom message'
...         if isinstance(e, TypeError):
...             return 'TypeError'
...         if isinstance(e, ValueError):
...             return 'ValueError'
...         return type(e).__name__
...     return 'no error'

-----------------
A scalar, a string, a float, inf or nan is a ValueError for NumPy 1.15.0.
None and a dict are a TypeError.
