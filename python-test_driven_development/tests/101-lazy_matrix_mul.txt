================================
Test cases for lazy_matrix_mul()
================================

The function multiplies two matrices with NumPy. The valid products are
the same as for matrix_mul(), but invalid arguments raise the exceptions
of NumPy instead of the messages of matrix_mul(). The class (a TypeError or
a ValueError) and the message of these exceptions depend on the NumPy
version, so every invalid example only checks that NumPy raised an error
of one of these two classes. Only the shapes that can't be multiplied are
checked for the exact ValueError, because it is raised by every version.
The products are shown as lists with tolist() so that no NumPy specific
repr is printed.

>>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Helpers that tell which kind of exception NumPy raised
------------------------------------------------------
The messages of NumPy depend on its version and never name m_a or m_b.
error() gives the same label for a TypeError and for a ValueError.
failure() gives the exact class name and is used only when every
version of NumPy raises the same class.

>>> def failure(m_a, m_b):
...     try:
...         lazy_matrix_mul(m_a, m_b)
...     except Exception as e:
...         if 'm_a' in str(e) or 'm_b' in str(e):
...             return 'custom message'
...         if isinstance(e, ValueError):
...             return 'ValueError'
...         if isinstance(e, TypeError):
...             return 'TypeError'
...         return 'other exception'
...     return 'no exception'
>>> def error(m_a, m_b):
...     try:
...         lazy_matrix_mul(m_a, m_b)
...     except Exception as e:
...         if 'm_a' in str(e) or 'm_b' in str(e):
...             return 'custom message'
...         if isinstance(e, (TypeError, ValueError)):
...             return 'error'
...         return 'other exception'
...     return 'no exception'
