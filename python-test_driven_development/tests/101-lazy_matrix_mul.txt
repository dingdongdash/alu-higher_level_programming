================================
Test cases for lazy_matrix_mul()
================================

The function multiplies two matrices with NumPy. The valid products are
the same as for matrix_mul(), but invalid arguments raise the exceptions
of NumPy, whose messages depend on the NumPy version. The examples only
rely on facts that hold for every version, and the products are shown
as lists with tolist() so that no NumPy specific repr is printed.

>>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

-------------------------------------

The arguments are unchanged
---------------------------
>>> m_a = [[1, 2], [3, 4]]
>>> m_b = [[5, 6], [7, 8]]
>>> print(lazy_matrix_mul(m_a, m_b).tolist())
[[19, 22], [43, 50]]
>>> m_a
[[1, 2], [3, 4]]
>>> m_b
[[5, 6], [7, 8]]
>>> result = lazy_matrix_mul(m_a, m_b)
>>> result[0][0] = 0
>>> m_a
[[1, 2], [3, 4]]
>>> m_b
[[5, 6], [7, 8]]

Helper that tells which kind of exception NumPy raised
------------------------------------------------------
The messages of NumPy depend on its version and never name m_a or m_b.

>>> def failure(m_a, m_b):
...     try:
...         lazy_matrix_mul(m_a, m_b)
...     except Exception as error:
...         if 'm_a' in str(error) or 'm_b' in str(error):
...             return 'custom message'
...         for kind in (ValueError, TypeError):
...             if isinstance(error, kind):
...                 return kind.__name__
...         return 'other exception'
...     return 'no exception'
