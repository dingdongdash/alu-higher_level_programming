# python-classes

Python scripts introducing classes and objects (Ubuntu 20.04, Python 3.8.5, pycodestyle 2.7.*).

| File | Description |
|------|-------------|
| `0-square.py` | Defines an empty class `Square` |
| `1-square.py` | Defines a `Square` with a private `size` attribute |
| `2-square.py` | Validates the type and value of `size` |
| `3-square.py` | Adds a public method `area()` returning the square area |
| `4-square.py` | Adds a `size` property with a getter and a validating setter |
| `5-square.py` | Adds `my_print()` to print the square with `#` |
| `6-square.py` | Adds a validated `position` property used by `my_print()` |
