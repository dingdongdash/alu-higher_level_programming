# python-import_modules

Python scripts exercising imports and command-line arguments (Ubuntu 20.04, Python 3.8.5, pycodestyle 2.7.*).

| File | Description |
|------|-------------|
| `0-add.py` | Imports `add` from `add_0` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports `add`, `sub`, `mul`, `div` from `calculator_1` and prints four results |
| `2-args.py` | Prints the number of arguments and lists them |
| `3-infinite_add.py` | Prints the sum of all arguments |
| `4-hidden_discovery.py` | Prints the names defined in `hidden_4.pyc`, sorted |
| `5-variable_load.py` | Imports `a` from `variable_load_5` and prints it |
