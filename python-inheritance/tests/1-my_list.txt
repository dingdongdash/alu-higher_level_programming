Doctests for the MyList class defined in 1-my_list.py
=====================================================

Load the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a subclass of list:

    >>> issubclass(MyList, list)
    True
    >>> isinstance(MyList(), list)
    True
    >>> MyList.__bases__
    (<class 'list'>,)

Printing an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []
    >>> print(my_list)
    []

Appending values and printing them sorted, the list stays unchanged:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

A list that is already sorted:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

A list sorted in reverse order:

    >>> my_list = MyList([5, 4, 3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [5, 4, 3, 2, 1]

Duplicated values:

    >>> my_list = MyList([3, 1, 3, 2, 1])
    >>> my_list.print_sorted()
    [1, 1, 2, 3, 3]

Negative values and zero:

    >>> my_list = MyList([3, -1, 0, -7, 2])
    >>> my_list.print_sorted()
    [-7, -1, 0, 2, 3]
    >>> print(my_list)
    [3, -1, 0, -7, 2]

A list with a single element:

    >>> my_list = MyList([42])
    >>> my_list.print_sorted()
    [42]

Calling the method several times gives the same result:

    >>> my_list = MyList([2, 3, 1])
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> my_list
    [2, 3, 1]

Inherited list behaviour keeps working:

    >>> my_list = MyList([2, 3, 1])
    >>> len(my_list)
    3
    >>> my_list.sort()
    >>> my_list
    [1, 2, 3]

The method takes no argument:
