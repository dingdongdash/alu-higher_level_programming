# python-more_classes

Python scripts going further with classes and objects (Ubuntu 20.04, Python 3.8.5, pycodestyle 2.7.*).

| File | Description |
|------|-------------|
| `0-rectangle.py` | Defines an empty class `Rectangle` |
| `1-rectangle.py` | Adds validated private `width` and `height` properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__` to print the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` so `eval(repr(rect))` builds a new rectangle |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the public class attribute `number_of_instances` |
| `7-rectangle.py` | Adds the public class attribute `print_symbol` |
| `8-rectangle.py` | Adds the static method `bigger_or_equal()` |
| `9-rectangle.py` | Adds the class method `square()` |
