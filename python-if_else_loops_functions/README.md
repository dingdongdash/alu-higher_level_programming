# Python - if/else, loops, functions

Tasks for the `python-if_else_loops_functions` project (Python 3.8.5, Ubuntu 20.04, pycodestyle 2.7.*).

- `0-positive_or_negative.py`: prints whether a random number is positive, zero or negative
- `1-last_digit.py`: prints the last digit of a random number and how it compares to 5
- `2-print_alphabet.py`: prints the lowercase alphabet
- `3-print_alphabt.py`: prints the lowercase alphabet except `q` and `e`
- `4-print_hexa.py`: prints 0 to 98 in decimal and hexadecimal
- `5-print_comb2.py`: prints 00 to 99
- `6-print_comb3.py`: prints all distinct two-digit combinations
- `7-islower.py`: `islower(c)` checks for a lowercase character
- `8-uppercase.py`: `uppercase(str)` prints a string in uppercase
- `9-print_last_digit.py`: `print_last_digit(number)` prints and returns the last digit
- `10-add.py`: `add(a, b)` returns the sum
- `11-pow.py`: `pow(a, b)` returns `a ** b`
- `12-fizzbuzz.py`: `fizzbuzz()` prints the Fizz Buzz sequence from 1 to 100
